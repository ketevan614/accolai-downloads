# Accolai Downloads

Installers for Accolai, a desktop music sequencer and MIDI editor.

Download the latest available installer from this repository's [Releases](https://github.com/ketevan614/accolai-downloads/releases) page. Run the installer for your operating system and follow its prompts.

This repository contains release downloads and documentation only. It does not contain the Accolai application source code.

Accolai builds on the [ryohey/signal](https://github.com/ryohey/signal) project, licensed under the MIT License. The license notice is included with the desktop application.
